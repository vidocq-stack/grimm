== Architecture du runner

Le runner officiel est dans `grimm-tck` (hors réacteur) :

- TestNG + Arquillian
- container custom `GrimmDeployableContainer`
- stack runtime : Vauban + Cassini/Chappe + Grimm

== Contrat qualité

Toute évolution structurelle de `grimm-core` ou `grimm-cdi-vauban` doit préserver
le score TCK complet.
