= Configuration MP OpenAPI
:description: Clés de configuration MicroProfile OpenAPI consommées par Grimm.

Grimm consomme les clés de configuration `mp.openapi.*` (via MP Config / Ravel).

== Clés principales

- `mp.openapi.model.reader`
- `mp.openapi.filter`
- `mp.openapi.scan.disable`
- `mp.openapi.scan.packages`
- `mp.openapi.scan.classes`
- `mp.openapi.scan.exclude.packages`
- `mp.openapi.scan.exclude.classes`
- `mp.openapi.servers`
- `mp.openapi.schema.<FQCN>`
- `mp.openapi.extensions.scan.disable`

== Exemples

[source,properties]
----
mp.openapi.scan.packages=com.acme.api
mp.openapi.scan.exclude.classes=com.acme.api.internal.InternalResource
mp.openapi.model.reader=com.acme.api.openapi.CustomReader
mp.openapi.filter=com.acme.api.openapi.CustomFilter
mp.openapi.servers=https://api.acme.dev,https://api.acme.prod
----

== Comportement important

- `exclude` est prioritaire sur `include`
- `mp.openapi.scan.disable=true` désactive complètement le scan annotations
- `mp.openapi.schema.<FQCN>` permet de surcharger le schéma d'une classe précise

== Endpoint `/openapi`

- `?format=json` force JSON
- `?format=yaml` force YAML
- sans `format`, négociation via `Accept` (YAML par défaut)
