= Getting started
:description: First steps with Grimm — MicroProfile OpenAPI 4.1 for Vidocq.

== Prerequisites

- Java 25
- Maven 4.0.0-rc-5
- Official TCK artifact installed locally (see `grimm-tck/README.md`)

== Local build

[source,bash]
----
sdk env
./mvnw -ntp install -DskipTests
./mvnw test
----

== Official TCK

[source,bash]
----
./run-official-tck-mp-openapi-4.1.sh smoke
./run-official-tck-mp-openapi-4.1.sh all
./run-official-tck-mp-openapi-4.1.sh matrix PetStoreAppTest
./run-official-tck-mp-openapi-4.1.sh -Dtest=AnnotationScanTest
----

== `/openapi` endpoint

`grimm-cdi-vauban` exposes a JAX-RS endpoint:

- path: `/openapi`
- formats: `application/yaml` (default) and `application/json`
- format priority: query param `format` (`json|yaml`) then `Accept` header
